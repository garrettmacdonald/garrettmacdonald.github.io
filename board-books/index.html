100 interactive board books for babies

Books a baby can do something with: touch-and-feel pages, lift-the-flaps, felt flaps, peekaboo die-cuts, pull and slide tabs, finger puppets and mirrors.

No single authoritative top 100 exists, and most lists online are affiliate blogs. This order puts first the long-running classics and bestsellers those lists keep repeating (Pat the Bunny, Dear Zoo, Spot, Peek-a-Who?, the Usborne "That's Not My…" series, Karen Katz flaps, Matthew Van Fleet, DK Touch and Feel). Where a series has many titles, the one listed is usually the one Connecticut libraries actually stock; any sister title works the same way.

A library tip: libraries buy few flap and texture books because they get torn, so many of these have only a handful of copies. The "CT libraries" link opens the Library Connection catalog (about 30 Hartford-area libraries, free holds between them). Copies there will show some wear.
